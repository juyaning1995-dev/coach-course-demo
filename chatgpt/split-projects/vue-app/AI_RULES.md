# AI 修改代码规则

1. 已跑通的业务逻辑不得随意重构。
2. UI 调整默认只允许修改样式，不允许修改业务逻辑。
3. 不得随意删除、重命名、移动已有变量、函数、事件、接口字段。
4. Vue 页面中，v-model、@click、v-if、v-for、props、emit、ref、computed、watch 不能随意改。
5. 修改前必须先理解页面状态、事件、数据流。
6. 修改后必须检查页面原有交互是否仍然可用。
7. 如果用户要求"只改颜色/样式"，不得改布局和逻辑。
8. 如果必须改结构，必须先说明原因。

# Figma 可编辑稿生成标准

使用 Claude Code + 官方 Figma MCP (`use_figma`) 将项目页面写入 Figma 时遵循。

## 生成要求

1. 在当前 Figma 文件中新建 Frame
2. Frame 尺寸与代码中的设计一致（电话端默认 390×844）
3. Frame 命名规范：**【页面名称】-可编辑稿**
4. 不使用截图，不导入整张图片
5. 使用 Figma 可编辑图层重建页面：文本、矩形、按钮、卡片、输入框、图标占位等
6. 保留原页面的：布局结构、颜色风格、字号层级、圆角、间距、按钮样式
7. 字体统一使用 Inter（Semi Bold / Regular），遇异常用 Figma 默认字体
8. 图标用简单线性图标或占位图形（圆点、椭圆等）替代
9. 图片用圆形/矩形占位图层替代，标注用途
10. 完成后读取或截图当前 Frame 检查完整性
11. 内容不完整则继续补全，不重新创建 Frame

## 禁止事项

- 不使用 localhost 开发服务器
- 不使用 claude-talk-to-figma-mcp
- 不输出纯说明文档而不写代码
- 不反复讨论配置
- Figma MCP 已 connected 时直接使用 use_figma 写页面
