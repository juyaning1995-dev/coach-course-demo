# 教练端课程预约管理系统 — 需求文档

## 1. 系统概述

双端SPA（单页应用），模拟微信小程序环境（手机壳 390×844px），教练端管理课程/排班，用户端浏览课程并预约。

- 教练端入口：`/coach-app/`
- 用户端入口：`/user-app/`
- 数据存储：浏览器 localStorage（均带 `coachSplit` 前缀）
- 预览命令：`node preview-server.cjs`（端口 8765）

---

## 2. 全局组件

### 2.1 手机壳框架
- 尺寸 390×844px，居中显示，深色背景
- 模拟状态栏（时间 9:41、信号图标、电池图标）

### 2.2 导航栏（Nav）
- 居中标题（`nav-title`）
- 左返回按钮（`nav-back`）：SVG 箭头图标
- 右胶囊按钮组（`nav-capsule`）：更多（三个点）+ 关闭（圆圈内含实心圆）
- 首页不显示返回按钮；Tab 页（课程/排班）不显示返回，通过底部导航切换

### 2.3 底部导航栏（教练端）
- 固定在手机壳底部，4个Tab：首页、课程、排班、我的
- 选中态橙色高亮，带图标SVG
- 高度 80px，毛玻璃背景

### 2.4 弹窗组件
- **课程审核弹窗**（auditMask）：模拟审核通过/驳回
- **时间选择器**（pickerMask）：日期+时间双下拉
- **课次操作面板**（opMask）：查看详情/代约/编辑/停止/取消/删除
- **代约确认弹窗**（memberBookMask）：确认代学员预约
- **无工作时间提示**（scheduleTipMask）：引导设置工作时间
- **预约确认弹窗**（userConfirmMask）：确认预约信息

### 2.5 Toast 提示
- 底部居中，白色半透明背景，1.5秒自动消失

### 2.6 FAB 悬浮按钮
- 右下角橙色圆形按钮（+），支持拖拽移动
- 课程列表页、排班日历页显示

## 3. 教练端功能

### 3.1 首页 — 教练工作台
- **统计卡片**（3列）：本月课次 / 学员数 / 完课数，含变化趋势
- **今日待办**：展示今日课次，显示时间、学员名、状态标签
- **快捷入口**（4列金刚区）：课程管理 / 工作时间 / 课程排班 / 签到
- **课程列表**：最近课程卡片，点击查看详情

### 3.2 课程管理

#### 3.2.1 课程列表
- 搜索框：按课程名称模糊搜索
- 状态筛选下拉：全部 / 待审核 / 已上架 / 审核驳回 / 已下架
- 课程卡片：课程名称、元信息（类型/课时/价格）、状态标签、驳回原因
- 操作按钮按状态变化：
  - 待审核：编辑 / 撤回
  - 已上架：编辑 / 下架 / 删除
  - 审核驳回：编辑 / 删除
  - 已下架：编辑 / 上架 / 删除

#### 3.2.2 新增/编辑课程表单
| 字段 | 类型 | 说明 |
|------|------|------|
| 课程名称 | text | 必填 |
| 授课形式 | select | 一对一 / 一对多 |
| 限制人数 | number | 一对多时显示 |
| 计费单位 | select | 按节 / 按时间 |
| 单节时长 | number | 按节时显示（分钟） |
| 课时 | number | 总课时数 |
| 售价 | number | 元 |
| 限购次数 | number | |
| 赠送课时 | number | |
| 赠送天数 | number | 按时间计费时显示 |
| 有效期 | number | 固定天数 |
| 激活方式 | select | 购买即生效 / 首次预约生效 / 指定天数后生效 |
| 提前预约时间 | number | 小时 |
| 适用门店 | text | |
| 课程简介 | textarea | |
| 课程说明 | textarea | 购买时展示给学员 |

- **表单草稿**：输入自动保存到 localStorage，离开页面不丢失
- **审核流程**：新增 → 待审核 → 弹窗模拟审核 → 通过（已上架）/ 驳回（审核驳回）
- 驳回后重新提交自动回到待审核状态

### 3.3 工作时间
- 按周一~周日展示已设置的时间段
- 未设置时显示空状态引导
- **编辑页面**：
  - 选择工作日（点击星期标签切换选中）
  - 设置时间段（上午/下午/晚上），可添加/删除
  - 每个时间段可开关（启用/停用）
  - 自动保存草稿
- 设置的时间作为排课可选时间范围

### 3.4 课程排班

#### 3.4.1 日历视图
- 周视图，左右箭头切换周，今天按钮快速定位
- 日期栏（周一~周日），选中日期高亮
- 时间轴：左侧时间标签（每半小时），右侧课程轨道
- 课次色块按状态着色：
  - **绿色**：可预约
  - **蓝色**：部分已约
  - **紫色**：已满
  - **灰色**：不可预约（已停止）
- 底部图例固定显示
- 点击课次弹出操作面板

#### 3.4.2 新增课次
| 字段 | 说明 |
|------|------|
| 选择课程 | 下拉选已上架课程 |
| 开始时间 | 日期时间选择器 |
| 结束时间 | 日期时间选择器 |
| 上课门店 | 自动带入课程适用门店 |
| 人数限制 | 自动带入课程人数限制 |

- 日历上的空位点按可直接带入日期

#### 3.4.3 课次操作
- **查看详情**：课次信息 + 已预约学员列表
- **代学员预约**：选择购买该课程的会员进行代约
- **编辑课次**：修改时间/门店/人数
- **停止预约**：停止后学员无法再预约，已有预约不受影响
- **取消课次**：标记为已取消
- **删除课次**：从系统中移除

### 3.5 我的页面
- **教练信息卡片**：头像（支持上传）、姓名（王美丽）、门店（振华商厦店）
- **统计网格**：本月课次 / 学员数 / 完课数
- **菜单列表**：
  - 门店签约
  - 会员合同
  - 工作时间
  - 课程管理

### 3.6 教练信息编辑
- 头像上传（点击更换，支持图片文件）
- 照片墙展示
- 教练信息字段可编辑（编辑/保存切换）
- 底部保存栏

### 3.7 会员合同
- 展示已签约会员的合同列表

## 4. 用户端功能

### 4.1 用户首页
- 课程网格展示（私教课/小班课分类）
- 点击课程进入详情

### 4.2 课程列表
- 展示可购买的课程（已上架状态）
- 课程卡片含名称、类型、价格、课时信息

### 4.3 购买流程
1. **选择课程** → 查看课程详情
2. **确认订单** → 显示课程信息、订单金额 ¥100、订单说明（7天可退、信息对教练可见）
3. **微信支付**（模拟） → 支付成功页
4. **签署电子合同** → 完成签署后进入预约

### 4.4 预约流程
1. **选择时段**：日期条（横向滑动）+ 时间段列表
   - 上午/下午/晚上分组
   - 显示每个时段状态：可约 / 已满 / 已约
   - 剩余课时不足时禁用预约
2. **确认预约**：弹窗显示预约详情
3. **预约成功**：展示预约摘要 + 规则说明
   - 预约使用1节对应课时
   - 每日21:00更新后续时间，每周六21:00更新下周
   - 同课程单日最多2次
   - 提前一天取消，训练当日不可取消

### 4.5 我的预约
- 预约列表：课程名、教练、门店、时间、状态
- 操作按钮：
  - 待上课：取消预约（距开课≥3小时）/ 联系教练取消（<3小时）
  - 待确认完课：确认完课
- 状态标签：待上课 / 已完课 / 已取消 / 待教练处理取消 / 待学员确认完课 / 未到场

### 4.6 教练主页
- 轮播图（照片墙）
- 教练信息：头像、姓名、技能标签、简介
- 私教课列表
- 精品小班课列表
- 上课门店列表

## 6. 技术架构

### 6.1 文件结构
```
split-projects/
├── coach-app/
│   ├── index.html        # 教练端页面（39行HTML + 外部JS引用）
│   └── js/
│       └── app.js        # 教练端全部业务逻辑（~1800行）
├── user-app/
│   ├── index.html        # 用户端页面（40行HTML + 外部JS引用）
│   └── js/
│       └── app.js        # 用户端业务逻辑
├── shared/
│   └── css/
│       ├── coach-base.css  # 公共基础样式（含暗黑主题CSS变量）
│       └── user-base.css   # 用户端专属样式
├── preview-server.cjs     # 静态文件预览服务
├── tests/                 # 单元测试和集成测试
└── package.json
```

### 6.2 UI风格
- 模拟微信小程序手机壳（390×844px）
- 深色主题（暗黑背景 #090909）
- 橙色主色调（#F8C900 金色用于关键元素，#FF6B35 用于交互高亮）
- 圆角卡片风格（18-28px border-radius）
- CSS变量驱动配色，定义在 `coach-base.css` 的 `body[data-app]` 块下

### 6.3 页面切换
- 单页伪路由：所有 `section.page` 默认隐藏，`.active` 显示
- 返回栈由 JS 管理，支持 Tab 页和普通页面的返回逻辑
- 底部导航在 Tab 页面（首页/课程/排班）显示

### 6.4 数据持久化
- 全部数据存储在 localStorage
- 表单输入实时自动保存草稿
- `resetAll()` 函数可清除所有数据（控制台执行）
