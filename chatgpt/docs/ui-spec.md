# 前端 UI 设计规范（移动端通用版）

====================================

一、设计目标

本规范用于统一移动端UI表现，确保页面：

- 清晰
- 一致
- 易读
- 可维护

所有UI必须遵循规范，不允许自由发挥设计。

====================================

二、整体风格

设计风格要求：

- 极简
- 高对比
- 卡片化
- 去装饰化

禁止：

- 渐变背景
- 插画背景
- 复杂纹理
- 视觉噪音

====================================

三、颜色规范

主色：

--color-primary: #FF6A00

中性色：

--color-bg: #F6F7F9
--color-card: #FFFFFF
--color-text-primary: #111827
--color-text-secondary: #6B7280
--color-text-tertiary: #9CA3AF
--color-border: #E5E7EB

状态色：

--color-success: #16A34A
--color-info: #2F80ED
--color-warning: #F59E0B
--color-danger: #EF4444

====================================

四、颜色使用规则

页面颜色占比：

- 背景色：60% - 70%
- 卡片色：20% - 30%
- 主色：5% - 10%

规则：

- 主色只用于强调（按钮、状态、选中）
- 不允许大面积使用主色背景
- 不允许使用超过3种主色系颜色
- 页面必须以中性色为主

====================================

五、字体规范

字体：

system-ui, -apple-system, PingFang SC, sans-serif

字号与字重：

页面标题：24px / 700
模块标题：18px / 700
卡片标题：16px / 600
正文：14px / 400
辅助文字：12px / 400
重点数字：28-32px / 700

行高：

标题：1.3
正文：1.5
辅助：1.4

====================================

六、间距规范

页面：

- 页面左右边距：16px

模块：

- 模块上下间距：12px
- 卡片内边距：16px
- 列表项间距：8px - 12px
- 宫格间距：12px

====================================

七、圆角规范

大卡片：18px
普通卡片：16px
小元素：12px
按钮：999px
标签：6px
头像：50%

====================================

八、阴影规范

统一使用轻阴影：

box-shadow: 0 8px 24px rgba(0,0,0,0.06);

禁止：

- 厚阴影
- 发光效果
- 多层叠加阴影

====================================

九、按钮规范

主按钮：

- 背景：主色
- 文字：白色
- 高度：40px
- 圆角：999px
- 字号：14px - 15px
- 字重：600

次按钮：

- 背景：白色
- 边框：1px solid 边框色
- 文字：主文字色

禁用按钮：

- 背景：#E5E7EB
- 文字：#9CA3AF

====================================

十、标签规范

标签尺寸：

- 字号：12px
- 内边距：4px 8px
- 圆角：6px

状态标签：

成功：浅绿背景 + 深绿文字
信息：浅蓝背景 + 蓝色文字
警告：浅橙背景 + 橙色文字
异常：浅红背景 + 红色文字

====================================

十一、卡片规范

卡片必须：

- 白色背景
- 圆角
- 内边距
- 轻阴影或浅边框

卡片结构：

- 标题区
- 内容区
- 操作区（可选）

====================================

十二、列表规范

列表要求：

- 行高统一（建议 ≥72px）
- 信息分层清晰
- 左信息 / 右操作或状态

禁止：

- 信息堆叠
- 字号混乱
- 间距不一致

====================================

十三、图标规范

- 使用统一图标库
- 风格必须一致（线性或面性）

尺寸：

- 常规：24px
- 功能入口：28px

颜色：

- 默认：主文字色
- 激活：主色

禁止：

- 多颜色混用
- 风格混乱

====================================

十四、布局规范

页面结构：

- 顶部区域
- 内容区域
- 底部区域（如导航）

内容布局：

- 卡片化优先
- 分块清晰
- 保持留白

禁止：

- 内容堆满
- 无间距布局
- 视觉拥挤

====================================

十五、禁止事项（强约束）

禁止：

- 随意修改设计风格
- 使用不在规范内的颜色
- 使用超过规范的字号体系
- 页面出现多种风格混搭
- 使用装饰性图片干扰信息
- 使用复杂背景
- UI不统一

====================================

十六、Codex执行规则

1. 所有UI修改必须遵循本规范
2. 不允许自由设计
3. 不允许自行扩展样式体系
4. 每次修改必须保持风格一致
5. 优先复用已有样式
6. 不允许破坏整体视觉统一性
